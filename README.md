## What'sInMyPack
What'sInMyPack is an AI-Powered app for analyzing packaged food products using Google Gemini, providing nutritional information, identifying hidden harmful ingredients, generating a one line summary and assigning a Nutri-Score Rating.

## Technologies Used
* Python
* Flet
* Google Gemini API
* JSON
* FilePicker Services(Flet)
* dotenv
  
## How It Works
1) User selects the photo of the desired food item
2) The selected photo is passed onto Google Gemini
3) Google Gemini returns the nutritional information, ingredients, potentially harmful ingredients, one line summary and Nutri-score Rating in JSON format
4) The extracted information is displayed in the form of a scrollable table.
   
## Disclaimer
What'sInMyPack uses AI-generated content  based on publicly available information.

Some information may be outdated, incomplete, or inaccurate. Users are advised to independently verify the information provided by the application before making dietary or health-related decisions.
